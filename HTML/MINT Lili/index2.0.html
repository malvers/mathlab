🌱 Automatisches Hochbeet

Smart Gardening mit dem Calliope mini

📋 Das Ziel

Baue ein System, das die Bodenfeuchtigkeit misst und dein Hochbeet automatisch bewässert, wenn die Erde zu trocken wird.

🛠️ Komponenten

  • 📟 Calliope mini
  • 💧 Feuchtigkeitssensor (P1)
  • 🔌 Schalterplatine (P2)
  • 🌊 Tauchpumpe & Netzteil

💻 Das Programm

So steuerst du deine Bewässerung manuell über die Tasten des Calliope mini:

Python Code (für Fortgeschrittene) 
from calliope_mini import *

while True:
    if button_a.is_pressed():
        # Pumpe an
        pin2.write_digital(1)
        display.show(Image.YES)
    
    if button_b.is_pressed():
        # Pumpe aus
        pin2.write_digital(0)
        display.show(Image.NO)

💡 Logik-Check:

  • Knopf A: Schaltet Pin 2 auf 1 (Strom fließt zur Pumpe).
  • Knopf B: Schaltet Pin 2 auf 0 (Strom wird unterbrochen).

🧪 Feuchtigkeits-Check

Verschiebe den Regler, um den Sensor zu testen:

Status: Boden ist feucht ✅
Pumpe ist aus

💡 Tipp: Wenn die Pumpe nicht läuft, tausche die Anschlüsse des Netzteils und der Pumpe an der Schalterplatine.

📖 Anschluss-Plan (nach deiner Skizze)

⚠️ WICHTIG: Verbinde den GND-Pin des Calliope mit dem Minus-Pol deines Moduls (Common Ground)!
  • Steuerung: Calliope P2 ➔ Modul Signal/IN+
  • Masse (GND): Calliope GND ➔ Modul IN- (Ganz wichtig!)
  • Diode 1 (Sicherung): In Reihe zwischen Modul OUT+ und der Kathode von Diode 2.
  • Diode 2 (Schutz): Parallel zur Pumpe, mit der Kathode an Pumpe (+).
  • Stromquelle: Netzteil (+) an Modul IN+ und (-) an Modul IN-.

💡 Hinweis: Die Diode 1 schützt dein System vor falscher Polung, Diode 2 schützt vor Spannungsspitzen des Motors.
