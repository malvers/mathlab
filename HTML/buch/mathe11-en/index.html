HOW TO USE THIS BOOK
EVERY CHAPTER HAS THE SAME STRUCTURE
  1. Opener with learning goals and a check-in: what you should already be able to do.
  2. Explorations: open questions to try out, ideally in groups.
  3. Units: starter, explanation, key-point box, examples, interactive elements, exercises and “Test yourself!”.
  4. Review · Deepen · Connect: mixed exercises.
  5. Excursion: history, an application or a nice puzzle.
  6. Looking back on one page and a test with two rounds.
