Functions and their properties

The price depends on how long you park, the temperature on the time of day, the braking distance on the speed. Dependencies like these are described with functions. Here you learn the common language for all the functions of this school year: domain, zeros, monotonicity, symmetry and more.

1What is a function?

On a summer's day the temperature is measured every three hours:

Time6912151821
°C141925272418

For every time there is exactly one temperature. Not necessarily the other way round: 18 °C, 19 °C or 24 °C can occur in the morning and in the evening.

KEY POINT · FUNCTION

A function $f$ assigns to every $x$ from a set $D$ exactly one $y$. You write $y = f(x)$ and call $f(x)$ the function value at $x$.

$D$ is called the domain, the set of all function values is called the range $W$.

A function can be represented as a verbal rule, a table of values, a term (equation of the function) or a graph.

Vertical line test: a curve is the graph of a function exactly when every vertical line meets it at most once. A circle fails the test: two points belong to $x = 0$.

Notation: $f: x \mapsto x^2$ is read “$f$ maps $x$ to $x^2$”. It means the same as $f(x) = x^2$.

Lab: the coordinate system tester trains reading off and plotting points.

EXAMPLE 2 · FROM TEXT TO TERM

A tradesman charges €45 call-out fee and €38 per hour of work. Give a term, a table and the range for at most 8 hours.

$K(t) = 45 + 38t$ with $0 \leq t \leq 8$.

$K(0) = 45$, $K(2) = 121$, $K(4) = 197$, $K(8) = 349$. Range: $45 \leq K \leq 349$ (in €).

EXERCISES

Is the assignment a function? a) person → height   b) positive number → its square roots   c) number → its square   d) car → number plate

a) yes   b) no, $9 \mapsto 3$ and $9 \mapsto -3$   c) yes   d) yes, every car has exactly one number plate

Let $f(x) = x^2 - 3x$. Calculate $f(0)$, $f(2)$ and $f(-1)$. Does $P(4, 4)$ lie on the graph?

$f(0) = 0$, $f(2) = -2$, $f(-1) = 4$. $f(4) = 16 - 12 = 4$, so yes.

Make a table of values for $g(x) = 2^x$ from $x = -2$ to $x = 3$ and draw the graph. State $D$ and $W$.

$0.25,\ 0.5,\ 1,\ 2,\ 4,\ 8$. $D = \mathbb{R}$, $W = \{y \mid y > 0\}$: the graph always stays above the $x$-axis.

A circle around the origin with radius 2 has the equation $x^2 + y^2 = 4$. Why is it not the graph of a function? Which two functions describe the upper and the lower semicircle?

$y = 2$ and $y = -2$ both belong to $x = 0$. Upper semicircle: $y = \sqrt{4 - x^2}$, lower: $y = -\sqrt{4 - x^2}$, each with $-2 \leq x \leq 2$.

Every natural number $n \geq 1$ is assigned the number of its divisors. Is this a function? Calculate $f(12)$ and $f(7)$. Which numbers have the function value 2?

Yes, every number has a definite number of divisors. $f(12) = 6$ (1, 2, 3, 4, 6, 12), $f(7) = 2$. Exactly the prime numbers have the value 2.

2Properties of functions

Describe the graph in the opener so precisely that someone could draw it over the phone. Where does it cross the $x$-axis? Where does it rise, where does it fall? Does it look the same on the left and on the right?

KEY POINT · PROPERTIES

Zero: a value $x_0$ with $f(x_0) = 0$. There the graph crosses or touches the $x$-axis.

Monotonicity: $f$ is increasing on an interval if $x_1 < x_2$ implies $f(x_1) \leq f(x_2)$, and decreasing if it implies $f(x_1) \geq f(x_2)$.

Symmetry: if $f(-x) = f(x)$ for all $x$, the graph is symmetric about the $y$-axis. If $f(-x) = -f(x)$, it is symmetric about the origin.

Periodicity: if $f(x + p) = f(x)$ for all $x$, $f$ is periodic with period $p$.

Asymptote: a line that the graph approaches as closely as you like without reaching it.

Memory aid: even powers like $x^2$, $x^4$ make a graph symmetric about the $y$-axis, odd ones like $x$, $x^3$ symmetric about the origin.

GeoGebra: Root(f) gives the zeros, you see the graph in the Graphics view.

INTERACTIVE · FUNCTION DETECTIVE

Choose a function, think about each property yourself and then uncover it.

EXAMPLE 3 · ZEROS AND SYMMETRY

Investigate $f(x) = x^3 - 4x$ for zeros and symmetry.

Factor out: $x(x^2 - 4) = x(x - 2)(x + 2) = 0$. Zeros: $x = -2$, $x = 0$, $x = 2$.

$f(-x) = (-x)^3 - 4(-x) = -x^3 + 4x = -f(x)$: symmetric about the origin. (The graph in the opener is $\tfrac14 f$.)

EXAMPLE 4 · ASYMPTOTES

Investigate $g(x) = \tfrac{1}{x - 2} + 1$.

You must not divide by $0$: $D = \mathbb{R} \setminus \{2\}$. Vertical asymptote $x = 2$, horizontal asymptote $y = 1$.

Zero: $\tfrac{1}{x - 2} = -1 \Rightarrow x - 2 = -1 \Rightarrow$ $x = 1$.

Find the zeros: a) $f(x) = 2x - 8$   b) $f(x) = x^2 - 9$   c) $f(x) = (x + 1)(x - 5)$

a) $x = 4$   b) $x = \pm 3$   c) $x = -1$ and $x = 5$ (a product is zero if one factor is zero)

a) $f(-x) = f(x)$: symmetric about the $y$-axis   b) $f(-x) = -f(x)$: symmetric about the origin   c) $f(-x) = x^2 - x$, neither $f(x)$ nor $-f(x)$: none of these symmetries

Describe the monotonicity of $f(x) = (x - 2)^2$ and state the range.

Decreasing for $x \leq 2$, increasing for $x \geq 2$. Lowest point $(2, 0)$, so $W = \{y \mid y \geq 0\}$.

Name three periodic processes from nature or technology and estimate the period of each.

For example: day length (one year), ebb and flow of the tide (about 12 h 25 min), heartbeat (about 0.8 s), mains voltage (0.02 s at 50 Hz).

Coffee cools down according to $T(t) = 20 + 60 \cdot 0.9^t$ ($t$ in min, $T$ in °C). State the asymptote, the range for $t \geq 0$ and the monotonicity. Interpret the asymptote.

Asymptote $y = 20$: the coffee approaches room temperature. $W$: $20 < T \leq 80$. $T$ is strictly decreasing.

Give a function with $D = \mathbb{R} \setminus \{0\}$, without a zero, symmetric about the $y$-axis.

For example $f(x) = \tfrac{1}{x^2}$ or $f(x) = \tfrac{1}{x^2} + 1$. There are many solutions.

TEST YOURSELF!

Which positive zero does $f(x) = x^2 - 16$ have?

$x^2 = 16$, positive: $x = 4$.

How is the graph of $f(x) = x^3 - x$ symmetric?

$f(-x) = -x^3 + x = -f(x)$

What is the smallest number in the domain of $f(x) = \sqrt{x - 3}$?

Nothing negative may stand under the root: $x - 3 \geq 0$, so $x \geq 3$.

Connecting with chapter 2: show by expanding that $-(x - 1)^2 + 4 = -x^2 + 2x + 3$, and find the zeros from the second form.

Can a function be symmetric about the $y$-axis and about the origin? Give reasons.

Then $f(x) = f(-x) = -f(x)$, so $f(x) = 0$ for all $x$. Only the zero function is both.

EXCURSIONFOOD FOR THOUGHT

Curves that are not graphs of functions

Circles, hearts, butterflies, even the Batman logo can be described with equations. But they fail the vertical line test. Mathematicians call them implicit curves: instead of $y = f(x)$ there is an equation between $x$ and $y$, for example $x^2 + y^2 = 4$.

To draw such curves you often split them into several graphs of functions, like the circle into an upper and a lower semicircle. In the lab you can see how a whole logo is made from many pieces of functions.

LOOKING BACKTHE ESSENTIALS AT A GLANCE

FUNCTION

Every $x$ from $D$ is assigned exactly one $y = f(x)$. Represented in words, as a table, a term or a graph.

$f(x) = x^2 - 3x$: $f(2) = -2$ · vertical line test for graphs

DOMAIN AND RANGE

Allowed $x$-values and possible $y$-values. Forbidden: dividing by 0, the root of a negative number.

$\tfrac{1}{x - 2}$: $D = \mathbb{R} \setminus \{2\}$ · $\sqrt{x - 3}$: $x \geq 3$

ZEROS

$f(x_0) = 0$. Factor out and use the zero-product rule.

$x^3 - 4x = x(x - 2)(x + 2)$: $x \in \{-2,\,0,\,2\}$

MONOTONICITY

Increasing: larger $x$, larger (or equal) $y$. Decreasing the other way round.

$(x - 2)^2$: decreasing for $x \leq 2$, increasing for $x \geq 2$

SYMMETRY

$f(-x) = f(x)$: symmetric about the $y$-axis · $f(-x) = -f(x)$: symmetric about the origin

$x^4 - x^2$ about the $y$-axis · $x^3 + x$ about the origin

PERIOD AND ASYMPTOTE

$f(x + p) = f(x)$ · a line that the graph approaches as closely as you like.

$\sin x$: period $2\pi$ · $20 + 60 \cdot 0.9^t$: asymptote $y = 20$

ROUND 1

Let $f(x) = x^2 - 5x$. Calculate $f(2)$.

$4 - 10 = -6$

Which zero does $f(x) = 2x + 6$ have?

$2x = -6 \Rightarrow x = -3$

How is $f(x) = x^4 + 2$ symmetric?

Only even powers (including the $2 = 2x^0$): $f(-x) = f(x)$.

ROUND 2

Which number does not belong to the domain of $f(x) = \tfrac{3}{x - 5}$?

$x = 5$, there the denominator would be 0.

How many zeros does $f(x) = (x - 1)^2 (x + 4)$ have?

Two: $x = 1$ (the graph touches the axis) and $x = -4$.

The graph of $T(t) = 20 + 50 \cdot 0.8^t$ has a horizontal asymptote $y = c$. What is $c$?

$0.8^t$ becomes as small as you like, so $T$ approaches the value 20.
