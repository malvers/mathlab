Rules of differentiation

Working out the limit of the difference quotient every time is tedious. Fortunately there are rules with which you can write down the derivative of almost any function in a few seconds, without aids. Here you learn the basic rules, from the power rule to the derivative of the logarithm, and you meet the only function that stays the same when you differentiate it. Products and compositions follow in chapter 2.4.

UNIT 14 LESSONS

1Power, constant multiple and sum rules

$(x^2)' = 2x$, $(x^3)' = 3x^2$, and with the difference quotient you find $(x^4)' = 4x^3$. The exponent moves to the front as a factor and goes down by 1.

If a function is stretched by a factor, all gradients are multiplied by this factor. If it is shifted upwards, the gradients do not change at all. And a sum changes as fast as its terms together.

KEY POINT · RULES OF DIFFERENTIATION

Power rule: $(x^n)' = n \cdot x^{n - 1}$   ·   Constant: $(c)' = 0$

Constant multiple rule: $(c \cdot f(x))' = c \cdot f'(x)$   ·   Sum rule: $(f(x) + g(x))' = f'(x) + g'(x)$

With these you differentiate every polynomial function term by term: $(a_n x^n + \ldots + a_1 x + a_0)' = n\,a_n x^{n-1} + \ldots + a_1$.

Brackets: multiply out products like $(2x - 1)(x + 3)$ or squares like $(x + 2)^2$ first, then differentiate.

Linear function: $(mx + n)' = m$. That fits chapter 2.2.

INTERACTIVE · DIFFERENTIATION TRAINER

Differentiate and type in your result, for example 6x^2 - 2, 1/(2sqrt(x)), e^x + cos x. It is checked at several points, the way you write it does not matter.

EXAMPLE 1 · TERM BY TERM

Differentiate $f(x) = 4x^5 - 3x^2 + 7x - 2$.

$f'(x) = 20x^4 - 6x + 7$

EXAMPLE 2 · MULTIPLY OUT FIRST

Differentiate $f(x) = (x + 2)^2$.

$f(x) = x^2 + 4x + 4$, so $f'(x) = 2x + 4$. Careful with shortcuts: for $(2x + 2)^2 = 4x^2 + 8x + 4$ the derivative is $8x + 8$, not $2(2x + 2)$.

Use the difference quotient to show that $(x^3)' = 3x^2$.

$\dfrac{(x + h)^3 - x^3}{h} = \dfrac{3x^2h + 3xh^2 + h^3}{h} = 3x^2 + 3xh + h^2 \to 3x^2$

Prove the power rule $(x^n)' = n \cdot x^{n - 1}$ for every natural number $n \ge 1$.

By the binomial theorem, $(x + h)^n = x^n + n x^{n - 1} h + \binom{n}{2} x^{n - 2} h^2 + \ldots + h^n$.

$\dfrac{(x + h)^n - x^n}{h} = \dfrac{n x^{n - 1} h + \binom{n}{2} x^{n - 2} h^2 + \ldots + h^n}{h} = n x^{n - 1} + h \cdot \Bigl(\binom{n}{2} x^{n - 2} + \ldots + h^{n - 2}\Bigr)$.

The bracket stays bounded for $h \to 0$, the factor $h$ tends to 0. So the limit is $n x^{n - 1}$.

UNIT 22 LESSONS

2Powers with rational and negative exponents

In chapter 2.2 we found the derivative $-1$ for $f(x) = \tfrac1x$ at 1. Does that fit the power rule if you write $\tfrac1x = x^{-1}$?

$(x^{-1})' = -1 \cdot x^{-2} = -\tfrac{1}{x^2}$, so $-1$ at 1. It fits. The power rule does not only hold for natural exponents.

KEY POINT · POWER RULE FOR ALL EXPONENTS

For every real number $r$ (and $x > 0$): $(x^r)' = r \cdot x^{r - 1}$.

$\left(\sqrt{x}\right)' = \left(x^{\frac12}\right)' = \tfrac12 x^{-\frac12} = \dfrac{1}{2\sqrt{x}}$   ·   $\left(\dfrac1x\right)' = -\dfrac{1}{x^2}$   ·   $\left(\dfrac{1}{x^2}\right)' = -\dfrac{2}{x^3}$

How to do it: first write roots and fractions as powers, then differentiate, then write them back.

Careful: $\sqrt{x}$ is not differentiable at $x = 0$, the tangent is vertical there.

EXAMPLE 3 · ROOT AND FRACTION

Differentiate $f(x) = 6\sqrt{x} - \dfrac{2}{x}$.

$f(x) = 6x^{\frac12} - 2x^{-1}$, so $f'(x) = 3x^{-\frac12} + 2x^{-2} = $ $\dfrac{3}{\sqrt{x}} + \dfrac{2}{x^2}$

EXAMPLE 4 · FRACTIONAL EXPONENT

Differentiate $f(x) = x\sqrt{x}$.

$x \cdot x^{\frac12} = x^{\frac32}$, so $f'(x) = \tfrac32 x^{\frac12} = $ $\tfrac32 \sqrt{x}$

UNIT 33 LESSONS

3The exponential function, sine and cosine

For $2^x$ the gradient at 0 is about 0.69, for $3^x$ about 1.10. For the base $\mathrm{e} \approx 2.718$ it is exactly 1. And even more: the function $\mathrm{e}^x$ has a gradient at every point that is exactly as large as its function value.

When sketching the derivative in chapter 2.2, the cosine curve came out of the sine curve. If you differentiate the cosine, you get the sine curve reflected in the $x$-axis.

KEY POINT · EXPONENTIAL FUNCTION, SINE AND COSINE

$(\mathrm{e}^x)' = \mathrm{e}^x$   ·   $(\sin x)' = \cos x$   ·   $(\cos x)' = -\sin x$

With the constant multiple and sum rules you combine them with powers: $(3\mathrm{e}^x - 2\sin x + x^2)' = 3\mathrm{e}^x - 2\cos x + 2x$.

If you differentiate the sine four times, you are back at the sine: $\sin \to \cos \to -\sin \to -\cos \to \sin$.

Radians: $(\sin x)' = \cos x$ only holds if $x$ is measured in radians. Set the calculator to RAD.

With a CAS you can also differentiate any other functions, for example to check.

EXAMPLE 5 · SUM

Differentiate $f(x) = 3\mathrm{e}^x - 2\sin x + x^2$.

$f'(x) = 3\mathrm{e}^x - 2\cos x + 2x$

EXAMPLE 6 · TANGENT TO THE EXPONENTIAL FUNCTION

Find the tangent to $f(x) = \mathrm{e}^x$ at the point $(1, \mathrm{e})$. Show that it passes through the origin.

$f'(1) = \mathrm{e}$, so $t(x) = \mathrm{e} + \mathrm{e}(x - 1) = \mathrm{e} \cdot x$.

$t(0) = 0$: the tangent is a line through the origin. It is the only tangent to $\mathrm{e}^x$ with this property.

EXERCISES

Differentiate: a) $5\mathrm{e}^x$   b) $\sin x + \cos x$   c) $\mathrm{e}^x - x^3$   d) $4\cos x$

a) $5\mathrm{e}^x$   b) $\cos x - \sin x$   c) $\mathrm{e}^x - 3x^2$   d) $-4\sin x$

What is the gradient of the graph of $f(x) = \mathrm{e}^x$ at 0, 1 and $-2$?

$1$; $\mathrm{e} \approx 2.718$; $\mathrm{e}^{-2} \approx 0.135$

Find the equation of the tangent to $f(x) = \sin x + \cos x$ at the point $(0, 1)$ and to $g(x) = 2\mathrm{e}^x - x^2$ at the point 0.

$f'(x) = \cos x - \sin x$, $f'(0) = 1$: $t(x) = x + 1$.   $g'(x) = 2\mathrm{e}^x - 2x$, $g(0) = 2$, $g'(0) = 2$: $t(x) = 2x + 2$.

At which points in $[0, 2\pi]$ does $f(x) = \sin x$ have a horizontal tangent?

$\cos x = 0$ at $x = \tfrac{\pi}{2}$ and $x = \tfrac{3\pi}{2}$

For which $x$ does $f(x) = \mathrm{e}^x - 2x$ have a horizontal tangent? Explain why there is only one such point, and decide whether there is a maximum or a minimum point there.

$f'(x) = \mathrm{e}^x - 2 = 0 \iff \mathrm{e}^x = 2 \iff x = \ln 2 \approx 0.693$. Because $\mathrm{e}^x$ is strictly increasing, it takes the value 2 only once.

To the left of it $f'(x) < 0$, to the right $f'(x) > 0$: minimum point $(\ln 2, 2 - 2\ln 2) \approx (0.693, 0.614)$.

UNIT 43 LESSONS

4The derivative of the logarithmic function

The natural logarithm $\ln x$ is the inverse function of $\mathrm{e}^x$: its graph is obtained by reflecting in the line $y = x$. The reflection turns every point $(u, v)$ into the point $(v, u)$ and every gradient triangle with “1 to the right, $m$ up” into one with “$m$ to the right, 1 up”. So the gradient becomes its reciprocal.

KEY POINT · DERIVATIVE OF ln x

$$(\ln x)' = \frac{1}{x} \quad \text{for } x > 0.$$

Reason: the point $(a, \ln a)$ on the graph of $\ln$ is the mirror image of $(\ln a, a)$ on the graph of $\mathrm{e}^x$. There $\mathrm{e}^x$ has the gradient $\mathrm{e}^{\ln a} = a$. Reflected, this becomes the gradient $\tfrac1a$.

With the laws of logarithms further terms can be differentiated without a new rule: $\ln(x^k) = k \ln x$ has the derivative $\tfrac{k}{x}$, and $\ln(c x) = \ln c + \ln x$ has the derivative $\tfrac1x$.

Slowly, but without limit: the gradient $\tfrac1x$ keeps getting smaller, but stays positive. That is why $\ln x$ grows more and more slowly and still beyond all bounds.

In the advanced course you must be able to differentiate $\ln x$ without aids. Other logarithms such as $\log_{10} x$ are differentiated with a CAS.

EXAMPLE 7 · WITH THE LAWS OF LOGARITHMS

Differentiate ($x > 0$): a) $f(x) = \ln(x^3)$   b) $g(x) = \ln(5x)$   c) $h(x) = 2x - 4\ln x$

a) $f(x) = 3\ln x$, so $f'(x) = \tfrac3x$   b) $g(x) = \ln 5 + \ln x$, so $g'(x) = \tfrac1x$   c) $h'(x) = 2 - \tfrac4x$

EXAMPLE 8 · TANGENT AT x = 1

Find the tangent to $\ln x$ at the point 1 and use the graph to justify that $\ln x \le x - 1$ for all $x > 0$.

$\ln 1 = 0$ and $(\ln x)' = \tfrac11 = 1$ at $x = 1$: $t(x) = x - 1$.

The graph of $\ln$ is concave everywhere (the gradient $\tfrac1x$ decreases) and therefore lies below each of its tangents. $\ln x \le x - 1$, with equality only at $x = 1$.

Differentiate ($x > 0$): a) $4\ln x$   b) $\ln x + x^2$   c) $\ln(x^2)$   d) $2 - \ln x$

a) $\tfrac4x$   b) $\tfrac1x + 2x$   c) $\tfrac2x$   d) $-\tfrac1x$

What is the gradient of the graph of $\ln x$ at the points $\tfrac12$, 1 and 10?

2; 1; 0.1

At which point does the graph of $\ln x$ have the gradient $\tfrac14$? Give the tangent there.

$\tfrac1x = \tfrac14$ at $x = 4$. $t(x) = \ln 4 + \tfrac14(x - 4) = \tfrac14 x + \ln 4 - 1 \approx 0.25x + 0.386$.

Investigate $f(x) = x - \ln x$ for $x > 0$: where is the tangent horizontal? Where does the graph fall, where does it rise?

$f'(x) = 1 - \tfrac1x = 0$ at $x = 1$. For $0 < x < 1$, $\tfrac1x > 1$, so $f'(x) < 0$: decreasing. Increasing for $x > 1$. Minimum point $(1, 1)$.

Show: the tangent to $\ln x$ at the point $(a, \ln a)$ passes through the origin if and only if $a = \mathrm{e}$. Compare with example 6.

$t(x) = \ln a + \tfrac1a(x - a)$, so $t(0) = \ln a - 1$. This is 0 exactly for $\ln a = 1$, so $a = \mathrm{e}$; the tangent is then $t(x) = \tfrac{x}{\mathrm{e}}$.

It is the mirror image of the tangent $y = \mathrm{e} \cdot x$ through the origin to $\mathrm{e}^x$ from example 6.

REVIEW · DEEPEN · CONNECT

A car brakes, its distance is $s(t) = 20t - 2t^2$ (m, s). How fast is it after 0 s and after 3 s? When does it stop?

$v(t) = s'(t) = 20 - 4t$: 20 m/s and 8 m/s. It stops when $v(t) = 0$, so after 5 s.

A bacterial culture grows according to $N(t) = 500 \cdot \mathrm{e}^t$ ($t$ in hours). Calculate the rate of growth after 2 hours. What do you notice when you compare it with $N(2)$?

$N'(t) = 500\,\mathrm{e}^t$, $N'(2) \approx 3695$ bacteria per hour, exactly as much as $N(2)$: the rate of growth is proportional to the population.

Connecting with Year 11: for the sine function $f(x) = 2\sin x$: what is the largest gradient, and at which points is it reached?

$f'(x) = 2\cos x$, so at most 2, at the points $x = 0, \pm 2\pi, \ldots$ (where it crosses zero going up).

Find a function $f$ with $f'(x) = 6x^2 - \cos x$ and $f(0) = 3$.

$f(x) = 2x^3 - \sin x + 3$. Check: $f'(x) = 6x^2 - \cos x$, $f(0) = 3$.

EXCURSIONA NUMBER FROM CALCULATING INTEREST

Euler's number e

In 1690 Jacob Bernoulli asked: what happens to 1 thaler at 100% interest per year if the interest is credited not once, but every half-year, every month, every day, indeed at every instant? Half-yearly gives $\left(1 + \tfrac12\right)^2 = 2.25$, monthly $\left(1 + \tfrac{1}{12}\right)^{12} \approx 2.613$, daily $\left(1 + \tfrac{1}{365}\right)^{365} \approx 2.715$.

The values grow, but not without bound. They tend to a number that Leonhard Euler later denoted by $\mathrm{e}$: $\mathrm{e} = \lim\limits_{n \to \infty} \left(1 + \tfrac1n\right)^n = 2.718\,281\,828\ldots$

The fact that $\mathrm{e}^x$ is its own derivative makes it the most important function for growth and decay in nature, technology and economics.

Sources: Jacob Bernoulli: Quaestiones nonnullae de usuris. Acta Eruditorum, 1690. Leonhard Euler: Mechanica, St Petersburg 1736.
