Antiderivatives

In Year 12 you turned a function into its rate of change. Now it goes backwards: you know the speed and look for the distance, you know the inflow and look for the amount of water. For this you need a function whose derivative is the given one, an antiderivative. This is the start of integral calculus, the big topic of the Abitur year.

UNIT 14 LESSONS

1Antiderivative and indefinite integral

$x^2$, $x^2 + 5$ and $x^2 - 3$ all have the derivative $2x$. A constant drops out when you differentiate, so you cannot get it back going backwards.

Every function $F$ with $F' = f$ is called an antiderivative of $f$. Once you have found one, you get all the others by adding a constant. Their graphs are shifted against each other in the $y$-direction and have the same gradient at every point.

KEY POINT · ANTIDERIVATIVE

$F$ is called an antiderivative of $f$ if $F'(x) = f(x)$ for all $x$.

If $F$ is an antiderivative, then all antiderivatives are of the form $F(x) + C$ with a constant $C$. You write them as the indefinite integral: $$\int f(x)\,\mathrm{d}x = F(x) + C.$$

Proof: whether $F$ is an antiderivative of $f$, you check by differentiating $F$.

Notation: $\mathrm{d}x$ shows the variable you integrate with respect to. The sign $\int$ is an elongated S, for “sum”.

Initial condition: if one point of the graph of $F$ is known, $C$ is fixed.

INTERACTIVE · ANTIDERIVATIVES AND THEIR GRADIENT
EXAMPLE 1 · PROOF

Show that $F(x) = \tfrac13 x^3 - x + 4$ is an antiderivative of $f(x) = x^2 - 1$.

$F'(x) = x^2 - 1 = f(x)$. ✓ The 4 does not matter, it is one choice for $C$.

EXAMPLE 2 · WITH AN INITIAL CONDITION

We want the antiderivative of $f(x) = 2x$ whose graph passes through $P(1, 5)$.

$F(x) = x^2 + C$, $F(1) = 1 + C = 5 \Rightarrow C = 4$. $F(x) = x^2 + 4$

EXERCISES

Check by differentiating: is $F$ an antiderivative of $f$? a) $F(x) = x^4 + 2$, $f(x) = 4x^3$   b) $F(x) = 3x^2$, $f(x) = 3x$

a) yes   b) no, $F'(x) = 6x$. Correct would be $\tfrac32 x^2$.

Give three different antiderivatives of $f(x) = 3x^2$.

For example $x^3$, $x^3 + 1$, $x^3 - 7.5$.

Find the antiderivative of $f(x) = 6x^2 - 4x$ through $P(1, 3)$.

$F(x) = 2x^3 - 2x^2 + C$, $F(1) = C = 3$. $F(x) = 2x^3 - 2x^2 + 3$

Exploration “From the speedometer to the distance”: find $s(t)$ with $s'(t) = 2t$ and $s(0) = 0$. How far does the car get in 5 seconds? What if it starts at $s(0) = 10$?

$s(t) = t^2$, $s(5) = 25$ m. Starting at 10 m: $s(t) = t^2 + 10$, after 5 s at the position 35 m, but the distance covered is also 25 m.

UNIT 24 LESSONS

2Integrating without aids: powers and sums

Differentiating $x^4$ gives $4x^3$. Backwards you have to raise the exponent by 1 and divide by the new exponent: $\int x^3\,\mathrm{d}x = \tfrac14 x^4 + C$.

Because differentiating leaves factors alone and treats sums term by term, the same holds for integrating.

KEY POINT · RULES OF INTEGRATION

Power rule: $\displaystyle\int x^r\,\mathrm{d}x = \frac{1}{r + 1}\,x^{r + 1} + C$ for $r \neq -1$, also for rational exponents.

Constant multiple rule: $\int c \cdot f(x)\,\mathrm{d}x = c \cdot \int f(x)\,\mathrm{d}x$   ·   Sum rule: $\int (f + g)\,\mathrm{d}x = \int f\,\mathrm{d}x + \int g\,\mathrm{d}x$

Constant: $\int c\,\mathrm{d}x = cx + C$. Always check by differentiating.

Why $r \neq -1$? For $\tfrac1x = x^{-1}$ you would have to divide by 0. One antiderivative is $\ln|x|$, but you do not need it in the foundation course.

Roots and fractions: write them as powers first, as when differentiating.

EXAMPLE 3 · POLYNOMIAL

Find $\int \left(6x^2 - 4x + 3\right) \mathrm{d}x$.

$2x^3 - 2x^2 + 3x + C$. Check: $(2x^3 - 2x^2 + 3x)' = 6x^2 - 4x + 3$ ✓

EXAMPLE 4 · ROOT AND FRACTION

Find $\int \sqrt{x}\,\mathrm{d}x$ and $\int \dfrac{1}{x^2}\,\mathrm{d}x$.

$\int x^{\frac12}\,\mathrm{d}x = \tfrac23 x^{\frac32} + C = \tfrac23 x\sqrt{x} + C$ · $\int x^{-2}\,\mathrm{d}x = \tfrac{1}{-1} x^{-1} + C = -\tfrac1x + C$

UNIT 34 LESSONS

3Antiderivatives of the exponential function, sine and cosine

From Year 12: $(\mathrm{e}^x)' = \mathrm{e}^x$, $(\sin x)' = \cos x$ and $(\cos x)' = -\sin x$. Which function has the derivative $\sin x$?

$(\cos x)'$ is $-\sin x$, so $-\cos x$ has the derivative $\sin x$. With the exponential function it is even simpler: it is its own antiderivative.

KEY POINT · EXPONENTIAL AND TRIGONOMETRIC FUNCTIONS

$\int \mathrm{e}^x\,\mathrm{d}x = \mathrm{e}^x + C$   ·   $\int \sin x\,\mathrm{d}x = -\cos x + C$   ·   $\int \cos x\,\mathrm{d}x = \sin x + C$

For all other functions that you cannot integrate without aids, you use a CAS. You can check every result by differentiating.

Memory aid: differentiating goes round in a circle $\sin \to \cos \to -\sin \to -\cos \to \sin$. Integrating runs the same circle backwards.

EXAMPLE 5 · MIXED

Find $\int \left(3\mathrm{e}^x + 2\sin x - x\right) \mathrm{d}x$.

$3\mathrm{e}^x - 2\cos x - \tfrac12 x^2 + C$

EXAMPLE 6 · CHECKED WITH A CAS

A CAS gives $\int x \cdot \mathrm{e}^x\,\mathrm{d}x = (x - 1)\,\mathrm{e}^x + C$. Check this by hand.

Product rule: $\left((x - 1)\,\mathrm{e}^x\right)' = 1 \cdot \mathrm{e}^x + (x - 1)\,\mathrm{e}^x = x\,\mathrm{e}^x$ ✓

EXERCISES

Find: a) $\int 2\mathrm{e}^x\,\mathrm{d}x$   b) $\int (\cos x - \sin x)\,\mathrm{d}x$   c) $\int (\mathrm{e}^x + 1)\,\mathrm{d}x$

a) $2\mathrm{e}^x + C$   b) $\sin x + \cos x + C$   c) $\mathrm{e}^x + x + C$

Find the antiderivative of $f(x) = \sin x$ with $F(0) = 0$. What is its value at $\pi$?

$F(x) = -\cos x + C$, $F(0) = -1 + C = 0 \Rightarrow C = 1$. $F(x) = 1 - \cos x$, $F(\pi) = 2$.

Show by differentiating that $F(x) = x\sin x + \cos x$ is an antiderivative of $f(x) = x\cos x$.

$F'(x) = \sin x + x\cos x - \sin x = x\cos x$ ✓

TEST YOURSELF!

Which function is an antiderivative of $\sin x$?

$(-\cos x)' = \sin x$

$F(x) = \mathrm{e}^x + C$ with $F(0) = 2$. What is $C$?

$\mathrm{e}^0 + C = 1 + C = 2 \Rightarrow C = 1$

a) $x^4 - 3x^2 + C$   b) $\tfrac14 x^2 + C$   c) $\tfrac13 x^3 + \mathrm{e}^x + C$

A ball is thrown vertically upwards with $v(t) = 15 - 10t$ (m/s), it starts at a height of 2 m. Find the height $h(t)$. When is it highest?

$h(t) = 15t - 5t^2 + 2$. Highest when $v(t) = 0$, so $t = 1.5$ s, with $h(1.5) = 13.25$ m.

Connecting with Year 12: the graph of $f'$ is a parabola opening upwards with zeros at $-1$ and $3$. What do you know about $f$? Give a suitable $f$.

$f$ has a maximum at $-1$ and a minimum at $3$. With $f'(x) = (x + 1)(x - 3) = x^2 - 2x - 3$, for example $f(x) = \tfrac13 x^3 - x^2 - 3x$.

Why is there no antiderivative of $f(x) = 2x$ whose graph passes through $(0, 1)$ and $(1, 1)$?

All antiderivatives are $x^2 + C$. From $(0, 1)$ it follows that $C = 1$, but then $F(1) = 2 \neq 1$. Two points are one condition too many.

EXCURSIONA LONG S FOR “SUM”

How the integral sign came about

In Paris, Gottfried Wilhelm Leibniz was looking for a notation for adding up infinitely many, infinitely narrow strips. In a manuscript of 29 October 1675 he wrote an elongated S for the first time, the initial letter of summa. In the same context he introduced the $\mathrm{d}$ for “difference”.

The sign appeared in print in 1686 in the journal Acta Eruditorum. Leibniz paid great attention to good notation, because it makes thinking easier. Today the whole world uses his $\int f(x)\,\mathrm{d}x$.

Source: G. W. Leibniz: De geometria recondita et analysi indivisibilium atque infinitorum. Acta Eruditorum, June 1686.

LOOKING BACKTHE ESSENTIALS AT A GLANCE

ANTIDERIVATIVE

$F' = f$. All antiderivatives: $F(x) + C$.

$f(x) = 2x$: $F(x) = x^2 + C$

POWER RULE

$\int x^r\,\mathrm{d}x = \tfrac{1}{r + 1} x^{r + 1} + C$, $r \neq -1$

$\int \sqrt{x}\,\mathrm{d}x = \tfrac23 x^{\frac32} + C$

CONSTANT MULTIPLE AND SUM RULES

Factors stay, terms one by one.

$\int (6x^2 - 4x + 3)\,\mathrm{d}x = 2x^3 - 2x^2 + 3x + C$

e AND TRIGONOMETRIC FUNCTIONS

$\int \mathrm{e}^x = \mathrm{e}^x$ · $\int \sin x = -\cos x$ · $\int \cos x = \sin x$, each $+ C$.

Always check by differentiating.
