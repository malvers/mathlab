CHAPITRE 3.3 · DOMAINE D’APPRENTISSAGE 3 · AVRIL

Plans

Un pan de toit, une façade vitrée, une rampe, le sol lui-même : les plans sont partout. Tu les décris de deux façons, avec un point et deux directions (représentation paramétrique) ou avec une seule équation $ax + by + cz = d$ (équation cartésienne). Et tu découvres où une droite perce un plan : c’est exactement ainsi qu’un ordinateur calcule où un rayon de soleil tombe sur un toit et où une ombre se pose.

LEÇON 14 HEURES

1Représentation paramétrique d’un plan

Trois pieds de tabouret qui ne sont pas alignés déterminent exactement un plan. Depuis le premier pied $A$, on atteint tout point du sol en avançant un peu dans la direction $\overrightarrow{AB}$ et un peu dans la direction $\overrightarrow{AC}$ : $\vec{x} = \vec{a} + r \cdot \overrightarrow{AB} + s \cdot \overrightarrow{AC}$. Deux paramètres, parce qu’un plan a deux directions.

À RETENIR · REPRÉSENTATION PARAMÉTRIQUE D’UN PLAN

$E\colon \vec{x} = \vec{p} + r \cdot \vec{u} + s \cdot \vec{v}$ avec le vecteur position $\vec{p}$ d’un point du plan et deux vecteurs directeurs $\vec{u}$, $\vec{v}$ linéairement indépendants ; $r, s \in \mathbb{R}$.

Un plan est déterminé par trois points non alignés, par une droite et un point extérieur à elle, par deux droites sécantes ou par deux droites strictement parallèles.

Test d’appartenance : $\vec{p} + r\vec{u} + s\vec{v} = \vec{q}$ est un système de trois équations pour $r$ et $s$. On les détermine avec deux d’entre elles et on vérifie avec la troisième.

Pas avec des droites non coplanaires : deux droites non coplanaires ne sont jamais dans un plan commun.

Quadrilatère plan ? Plan passant par trois sommets, test d’appartenance avec le quatrième. C’est ainsi qu’on vérifie si un toit vitré peut être fait d’une seule plaque.

Établis le plan passant par $A(1\,;\,0\,;\,0)$, $B(0\,;\,1\,;\,0)$, $C(0\,;\,0\,;\,1)$. Le point $Q(1\,;\,1\,;\,1)$ y est-il ?

$Q$ : $r = 1$, $s = 1$ d’après $y$ et $z$, puis $x = 1 - 1 - 1 = -1 \neq 1$ : $Q$ n’est pas dans $E$.

EXEMPLE 2 · TOIT PLAN ?

Les points $A(0\,;\,0\,;\,3)$, $B(4\,;\,0\,;\,3)$, $C(4\,;\,2\,;\,5)$ et $D(0\,;\,2\,;\,5)$ sont-ils dans un même plan ?

$\vec{x} = (0\,;\,0\,;\,3) + r(4\,;\,0\,;\,0) + s(4\,;\,2\,;\,2)$ ; pour $D$ : $2s = 2$, donc $s = 1$ ; $3 + 2 = 5$ convient ; $4r + 4 = 0$, donc $r = -1$.

Oui, $ABCD$ est plan, c’est même un rectangle.

LEÇON 24 HEURES

2Plans sans paramètre

Pour le plan passant par $(2\,;\,0\,;\,0)$, $(0\,;\,2\,;\,0)$, $(0\,;\,0\,;\,2)$, tous les points vérifiés satisfont $x + y + z = 2$. Par le calcul : $\vec{x} = (0\,;\,0\,;\,2) + r(1\,;\,0\,;\,-1) + s(0\,;\,1\,;\,-1)$ signifie $x = r$, $y = s$, $z = 2 - r - s$. Si l’on remplace les deux premières dans la troisième, les paramètres disparaissent : $z = 2 - x - y$, donc $x + y + z = 2$.

À RETENIR · ÉQUATION CARTÉSIENNE

Tout plan peut s’écrire $E\colon ax + by + cz = d$ ($a$, $b$, $c$ pas tous nuls). Un point est dans $E$ si ses coordonnées vérifient l’équation.

Points d’intersection avec les axes : annuler deux coordonnées. Équation par les points d’intersection avec les axes : $\dfrac{x}{p} + \dfrac{y}{q} + \dfrac{z}{r} = 1$ (pour $p, q, r \neq 0$), avec les points $(p\,;\,0\,;\,0)$, $(0\,;\,q\,;\,0)$, $(0\,;\,0\,;\,r)$.

Éliminer les paramètres : écrire la représentation paramétrique coordonnée par coordonnée, déterminer $r$ et $s$ avec deux équations et les remplacer dans la troisième. Retour : isoler une variable, choisir librement les deux autres.

Positions particulières : s’il manque une variable, le plan est parallèle à l’axe correspondant ($3x + 2y = 6$ ∥ axe des $z$) ; $d = 0$ : il passe par l’origine ; $y = 4$ : parallèle au plan $xz$.

Beaucoup d’équations, un seul plan : $2x - y + z = 3$ et $4x - 2y + 2z = 6$ décrivent le même plan. $4x - 2y + 2z = 10$ lui est parallèle.

Perspective : les nombres $a$, $b$, $c$ forment un vecteur perpendiculaire au plan. Ce vecteur normal, tu t’en serviras en 12e année pour les angles et les distances.

Détermine les points d’intersection de $E\colon 2x + 3y + 6z = 12$ avec les axes.

EXEMPLE 4 · ÉLIMINER

Détermine l’équation cartésienne de $\vec{x} = (1\,;\,1\,;\,1) + r(1\,;\,0\,;\,0) + s(0\,;\,1\,;\,1)$.

$x = 1 + r$, $y = 1 + s$, $z = 1 + s$. $r$ n’apparaît que dans $x$ : $x$ est libre.

De $y$ et $z$ : $y = z$, donc $y - z = 0$, un plan qui contient la direction $x$.

LEÇON 34 HEURES

3Position relative d’une droite et d’un plan

Le rayon de soleil qui passe par le sommet du mât est la droite $\vec{x} = (0\,;\,0\,;\,6) + t(2\,;\,1\,;\,-3)$. Au sol, $z = 0$ : $6 - 3t = 0$, donc $t = 2$, point d’ombre $(4\,;\,2\,;\,0)$. S’il y a dans cette direction une rampe de plan $x - 2z = 0$, on remplace les points de la droite dans son équation : $2t - 2(6 - 3t) = 0$, donc $t = 1{,}5$. C’est avant le sol ($t = 2$) : l’ombre tombe sur la rampe, au point $(3\,;\,1{,}5\,;\,1{,}5)$. On procède toujours ainsi : remplacer, déterminer $t$, vérifier dans le contexte.

À RETENIR · DROITE ET PLAN

Une droite peut couper un plan (exactement un point d’intersection), lui être parallèle (aucun point commun) ou être contenue dans le plan.

Avec l’équation cartésienne : remplacer les coordonnées de la droite $x(t)$, $y(t)$, $z(t)$ dans $ax + by + cz = d$. Une solution $t$ : point d’intersection · contradiction comme $0 = 5$ : parallèle · toujours vrai comme $2 = 2$ : la droite est contenue dans le plan.

Avec la représentation paramétrique : égaler ; trois équations pour $t$, $r$, $s$, résolues avec la méthode de Gauss.

Indice : si un plan est déjà donné par son équation cartésienne, remplacer est presque toujours plus rapide qu’égaler.

Ombres et miroirs : ombres portées, rayons laser, trajectoires à travers des couches de nuages : tout cela, c’est « une droite coupe un plan ».

EXEMPLE 6 · PARALLÈLE OU CONTENUE ?

$g\colon \vec{x} = (0\,;\,1\,;\,2) + t(1\,;\,0\,;\,-1)$ avec $E\colon x + z = 2$ et avec $F\colon x + z = 5$.

EXCURSIONIMAGERIE NUMÉRIQUE

Comment un ordinateur calcule des images

Chaque image d’un jeu vidéo ou d’un film d’animation est faite de millions de petits triangles plans. Pour décider de la couleur d’un pixel, l’ordinateur envoie depuis l’œil de l’observateur une droite à travers ce pixel dans la scène et détermine quel triangle elle perce en premier : « une droite coupe un plan », puis on vérifie encore si le point d’intersection est dans le triangle. Pour l’ombre, une seconde droite suit, du point d’intersection vers la lampe.

Ce ray casting a été décrit en 1968 par le chercheur d’IBM Arthur Appel. À l’époque, une image simple demandait longtemps ; aujourd’hui, les cartes graphiques calculent des milliards de tels points d’intersection par seconde. Les mathématiques sont les mêmes que dans ce chapitre.

Source : A. Appel, « Some techniques for shading machine renderings of solids », AFIPS Spring Joint Computer Conference 1968, vol. 32, p. 37–45.
