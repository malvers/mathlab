Chat-Schlüssel

Alle Teilnehmer müssen denselben Schlüssel eingeben. Nur damit können Nachrichten entschlüsselt werden.

Supabase Keys

Nach dem Starten: in Supabase SQL-Editor folgendes ausführen:
CREATE TABLE messages (id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY, created_at timestamptz DEFAULT now(), sender text NOT NULL, content text NOT NULL);
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow all" ON messages FOR ALL USING (true) WITH CHECK (true);
