Grundsatz

docalvers.de ist eine kostenlose, werbefreie Lernplattform für Mathematik und Informatik. Es gibt keine Nutzerkonten, keine Newsletter, kein Tracking und keine Analyse-Dienste. Personenbezogene Daten werden von uns weder erhoben noch gespeichert oder weitergegeben.

Lokale Speicherung (localStorage)

Einige Labore merken sich Einstellungen (z. B. Sprache oder Ansichts-Optionen) ausschließlich im lokalen Speicher deines Browsers. Diese Daten verlassen dein Gerät nicht und können jederzeit über die Browser-Einstellungen gelöscht werden.

Hosting und Server-Logs

Die Website wird über GitHub Pages (GitHub Inc.) ausgeliefert. Beim Abruf können technisch bedingt Server-Logdaten (z. B. IP-Adresse, Zeitpunkt) beim Hoster anfallen. Details: GitHub Privacy Statement.

Externe Dienste in einzelnen Laboren

Einige Labore laden Inhalte von Drittanbietern (z. B. Google Fonts, Kartendaten von OpenStreetMap, Wetterdaten von Open-Meteo, Enzyklopädie-Auszüge von Wikipedia). Dabei wird deine IP-Adresse an den jeweiligen Anbieter übertragen. Es werden keine weiteren Daten von uns übermittelt.

YouTube

Unsere Demo-Videos sind auf YouTube veröffentlicht und von den Lab-Seiten verlinkt (YouTube-Kanal Doc Alvers Mathe-Labor). Beim Öffnen eines Links gelten die Datenschutzbestimmungen von YouTube/Google.

Für die Veröffentlichung dieser Videos nutzen wir die YouTube-API-Dienste (YouTube API Services). Es gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung. Unser Upload-Werkzeug ist ein privates Kommandozeilen-Tool: Es lädt ausschließlich eigene Videos auf unseren eigenen Kanal hoch und greift auf keine Daten anderer Nutzer zu. Es werden keine YouTube-Nutzerdaten erhoben, gespeichert, geteilt oder verarbeitet. Die einzige gespeicherte Information ist das eigene OAuth-Zugriffstoken auf dem lokalen Rechner des Verantwortlichen; es kann jederzeit über die Google-Sicherheitseinstellungen widerrufen werden. Anfragen zur Datenlöschung richtest du an info@docalvers.de — gespeicherte Drittdaten existieren jedoch nicht.
