Welche stimmt? Niemand weiß es

Integrität: Regeln, die Konsistenz erzwingen

Konsistenz ist ein Zustand — Integrität sind die Regeln, die ihn sichern

Das DBMS prüft die Regeln bei jedem Einfügen, Ändern, Löschen

Verstoß → die Operation wird abgelehnt, nicht „irgendwie gespeichert“

Vier Regelarten: Entität, Referenz, Wertebereich, Semantik

Regeln im CREATE TABLE: das DBMS passt auf

-- Regeln, die das DBMS selbst überwacht
CREATE TABLE Lehrkraft (
  LNr        INTEGER PRIMARY KEY,               -- Entitätsintegrität
  Name       TEXT    NOT NULL,
  Durchwahl  INTEGER CHECK (Durchwahl BETWEEN 10 AND 99)  -- Wertebereich
);
CREATE TABLE Kurs (
  KNr   INTEGER PRIMARY KEY,
  Fach  TEXT    NOT NULL,
  Raum  TEXT    CHECK (Raum IN ('118', '204', '210', '305')),
  LNr   INTEGER NOT NULL REFERENCES Lehrkraft(LNr)   -- referentielle Integrität
);
