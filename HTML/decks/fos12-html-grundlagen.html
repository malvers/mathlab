Kapitel 01

Auszeichnen

HTML ist keine Programmiersprache

Nicht verzagen, Doc Alvers fragen!

Was HTML tut — und was nicht

HTML = HyperText Markup Language, eine Auszeichnungssprache

Sie beschreibt Struktur: Das ist eine Überschrift, das ein Absatz, das eine Liste

Sie rechnet nichts, entscheidet nichts, wiederholt nichts — keine Algorithmen

Wie es aussieht, bestimmt CSS (nächste Woche). Was passiert, bestimmt JavaScript

Der Browser liest den Text, baut daraus einen Baum und zeigt ihn an

Nicht verzagen, Doc Alvers fragen!

Die drei Grundbegriffe

BegriffBeispielbedeutet
Tag<p> … </p>Anfangs- und Endmarke, in spitzen Klammern
Element<p>Hallo</p>Tags samt Inhalt — ein Bauteil der Seite
Attribut<a href="…">Zusatzangabe im Anfangstag, Name="Wert"
leeres Element<img>, <br>hat keinen Inhalt, also keinen Endtag

Elemente werden verschachtelt, nie überkreuzt: zuletzt geöffnet = zuerst geschlossen

Der entstehende Baum heißt DOM — Document Object Model

Kopf und Körper

Zeilewozu
<!DOCTYPE html>sagt: das ist HTML5 — muss ganz oben stehen
lang="de"Sprache der Seite: wichtig für Vorlesesoftware und Suchmaschinen
<meta charset="UTF-8">Zeichensatz — ohne diese Zeile werden Umlaute zu Kauderwelsch
<meta name="viewport"…>Grundlage für die Darstellung auf dem Handy
<title>Text im Browser-Tab und im Suchergebnis
<head> / <body>Angaben ÜBER die Seite / der sichtbare Inhalt

Alles im head ist unsichtbar, aber nicht unwichtig

Der viewport ist die Eintrittskarte zum responsiven Layout

Fun Facts: HTML

Die erste Fassung von HTML kannte 1991 nur 18 Elemente — darunter kein einziges für Bilder

Das <img>-Element schlug Marc Andreessen 1993 vor; die Diskussion darüber dauerte drei Tage

Das <blink>-Element gab es wirklich — es gilt als schlechteste Idee der Webgeschichte

HTML5 hat kein Versionsende mehr: es ist ein „living standard“, der laufend wächst

Browser sind extrem nachsichtig: sie reparieren fehlerhaftes HTML still — was die Fehlersuche erschwert
