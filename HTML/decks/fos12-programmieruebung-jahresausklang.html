Aufgabe 1 — der Weihnachtsbaum

hoehe = int(input('Wie hoch? '))

for i in range(1, hoehe + 1):
    print(' ' * (hoehe - i) + '*' * (2 * i - 1))

print(' ' * (hoehe - 1) + '|')

#     *          hoehe = 4
#    ***
#   *****
#  *******
#     |

Nicht verzagen, Doc Alvers fragen!

Was in diesen vier Zeilen steckt

Zählschleife mit berechneten Grenzen — range(1, hoehe + 1)

Zeichenketten multiplizieren: '*' * 5 ergibt '*****'

Ein kleiner Zusammenhang zwischen i und der Breite: 2·i − 1 ist immer ungerade

Die Leerzeichen davor sind die Gegenrechnung — zusammen ergibt es die Mitte

Probiert es aus: Was passiert bei hoehe = 1? Bei hoehe = 0?

Aufgabe 2 — FizzBuzz, der Klassiker

# 1 bis 100: durch 3 teilbar -> Fizz, durch 5 -> Buzz, durch beide -> FizzBuzz

for i in range(1, 101):
    if i % 3 == 0 and i % 5 == 0:
        print('FizzBuzz')
    elif i % 3 == 0:
        print('Fizz')
    elif i % 5 == 0:
        print('Buzz')
    else:
        print(i)

# Die Reihenfolge der Bedingungen ist hier die ganze Aufgabe.

Aufgabe 3 — der Countdown mit Abbruch

import time

sekunden = int(input('Countdown ab: '))

while sekunden > 0:
    print(sekunden)
    sekunden = sekunden - 1
    time.sleep(1)

print('Frohe Weihnachten!')

Vorgehen beim Fehlersuchen

Lest die Fehlermeldung — die letzte Zeile sagt, was, die vorletzte, wo

Halbiert das Problem: an welcher Stelle stimmen die Werte noch?

Gebt Zwischenwerte aus — print(summe) in der Schleife zeigt sofort, was passiert

Rechnet den Testfall von Hand — wer das Ergebnis nicht kennt, sucht ins Blaue

Erklärt den Code laut einem Mitschüler; sehr oft findet man den Fehler beim Erzählen
