Variablen

Zuweisung ist keine Gleichung

In der Mathematik

x = x + 1 ist eine falsche Aussage

Das Gleichheitszeichen behauptet etwas

x steht für einen festen Wert

Im Programm

x = x + 1 ist ein Befehl

Rechte Seite ausrechnen, links hineinlegen

x ist ein Behälter, sein Inhalt ändert sich

Was beim Zuweisen passiert

punkte = 40        # in punkte liegt jetzt 40
punkte = punkte + 12   # rechts 52 ausrechnen, links hineinlegen
print(punkte)      # 52

a = 3
b = a              # b bekommt eine Kopie des Wertes
a = 99             # b bleibt 3 !
print(a, b)        # 99 3

Fun Facts: Datentypen

0.1 + 0.2 == 0.3 ist in fast jeder Sprache False — Kommazahlen werden binär gespeichert und passen nicht genau

Deshalb rechnen Banken mit Ganzzahlen in Cent, nicht mit float

Der Ariane-5-Absturz 1996 (370 Mio. $) entstand, weil eine 64-Bit-Kommazahl in 16 Bit gequetscht wurde

Python-Ganzzahlen haben keine Obergrenze — 2**1000 rechnet es klaglos aus

Das Wort Bug für Programmfehler ist älter als der Computer: Edison benutzte es 1878 für Störungen in Geräten
