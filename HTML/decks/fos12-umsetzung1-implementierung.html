Sieben Schritte — in dieser Reihenfolge

Schrittwas entstehtfertig, wenn …
1 GerüstOrdnerstruktur, index, stil.cssdie Startseite lädt mit Layout
2 NavigationKopf, Menü, Fuß auf allen Seitenjede Seite ist von jeder erreichbar
3 Statische InhalteTexte und Bilder zum Themadie Seite ist ohne Daten schon lesbar
4 DatenbankTabellen + Testdaten angelegtAbfragen laufen im DBMS
5 Verbindungeine Seite zeigt echte Datensätzedie Liste kommt aus der Datenbank
6 Eingabeein Formular schreibt in die Datenbankder neue Datensatz erscheint in der Liste
7 Restweitere Seiten nach demselben Musterder Anbindungsplan ist abgearbeitet

Schritt 5 ist der Meilenstein dieser Woche: eine Seite mit echten Daten

Nie zwei Baustellen gleichzeitig — erst wenn ein Schritt läuft, beginnt der nächste

Nicht verzagen, Doc Alvers fragen!

Ordnung im Projektordner

index.html ganz oben — der Einstiegspunkt heißt immer so

css/ für Stylesheets, bilder/ für Bilder, daten/ für die Datenbankdatei

Dateinamen klein, ohne Leerzeichen und ohne Umlaute — Server sind da strenger als Windows

Relative Pfade benutzen (bilder/apfel.jpg), keine Laufwerksbuchstaben

Eine Sicherungskopie je Arbeitstag — im Teamordner, mit Datum im Namen

Warum das der wichtigste Handgriff der Woche ist

Navigation und Fußzeile stehen einmal da — Änderung wirkt auf allen Seiten

Genau dasselbe Prinzip wie eine CSS-Datei für alle Seiten

Ohne Serverumgebung geht include nicht — dann kopiert ihr den Block und pflegt ihn bewusst

Vergesst nicht: Seiten mit PHP-Code müssen auf .php enden

Testet nach dem Umbau jede Seite einmal — ein fehlender Pfad fällt sonst erst spät auf

Ein Formular, das speichert

<form method="post" action="neu.php">
    <label for="name">Lebensmittel</label>
    <input type="text" id="name" name="name" required>

    <label for="kcal">kcal je 100 g</label>
    <input type="number" id="kcal" name="kcal" min="0" max="900" required>

    <button type="submit">Speichern</button>
</form>

<?php
if (isset($_POST['name'])) {
    $stmt = $db->prepare('INSERT INTO lebensmittel (name, kcal) VALUES (?, ?)');
    $stmt->execute([$_POST['name'], (int)$_POST['kcal']]);
    echo '<p>Gespeichert.</p>';
}
?>

Nicht verzagen, Doc Alvers fragen!

Drei Regeln, die ab jetzt immer gelten

method="post" für alles, was speichert — GET nur zum Abholen

prepare mit Platzhaltern, nie Nutzertext in den SQL-Text kleben

htmlspecialchars um jede Ausgabe, die aus der Datenbank oder vom Nutzer kommt

Jedes Eingabefeld braucht ein label — Pflicht für Barrierefreiheit und Bedienung

Warum das mehr als Stil ist, klären wir in Woche 30: SQL-Injection und XSS

Wann eine Aufgabe wirklich fertig ist

Kriteriumerfüllt, wenn …
Es läuftdie Seite lädt ohne Fehlermeldung
Es stimmtmindestens ein Testfall wurde durchgespielt und notiert
Es ist sauberHTML validiert, CSS getrennt, sprechende Namen
