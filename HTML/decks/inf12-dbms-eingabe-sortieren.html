Regelwird verletzt durchReaktion

Ändern und Löschen

UPDATE Schueler SET klasse = 'BGY24' WHERE snr = 2;

DELETE FROM Schueler WHERE snr = 3;

Die WHERE-Klausel ist der wichtigste Teil: ohne sie trifft es alle Zeilen

Ein vergessenes WHERE bei UPDATE ist der Klassiker unter den teuren Fehlern

Deshalb: erst als SELECT schreiben, prüfen, dann in UPDATE umwandeln

Daten ausgeben

SELECT in seiner Grundform

Die Grundform der Abfrage

SELECT *                       -- alle Spalten
FROM Schueler;                 -- aus dieser Tabelle

SELECT name, vorname           -- Projektion: nur diese Spalten
FROM Schueler;

SELECT name, vorname
FROM Schueler
WHERE klasse = 'BGY25';        -- Selektion: nur diese Zeilen

Nicht verzagen, Doc Alvers fragen!

Die beiden Grundoperationen

Operationwählt ausim SQL
ProjektionSpaltendie Liste hinter SELECT
SelektionZeilendie Bedingung hinter WHERE

Die Begriffe stammen aus der Relationenalgebra und werden in der Klausur verlangt

Beides zusammen ergibt einen Ausschnitt der Tabelle — waagerecht und senkrecht

Kapitel 03

Sortieren

ORDER BY und seine Tücken

Nicht verzagen, Doc Alvers fragen!

Sortiert ausgeben

SELECT name, vorname, klasse
FROM Schueler
ORDER BY name;                      -- aufsteigend ist Standard

SELECT name, vorname, geburt
FROM Schueler
ORDER BY geburt DESC;               -- juengste zuerst

SELECT klasse, name, vorname
FROM Schueler
ORDER BY klasse ASC, name ASC;      -- zwei Kriterien

Nicht verzagen, Doc Alvers fragen!

Worauf man beim Sortieren achtet

ASC ist die Voreinstellung, DESC kehrt die Reihenfolge um

Bei zwei Kriterien entscheidet das zweite nur bei Gleichstand im ersten

Eine Zahl im Textfeld sortiert als Text: „10“ steht vor „2“

NULL-Werte landen je nach DBMS am Anfang oder am Ende — nachsehen lohnt

Sortiert wird nur die Ausgabe — die gespeicherte Reihenfolge ist ohnehin nicht garantiert

Ohne WHERE trifft UPDATE und DELETE jede Zeile. Deshalb jede Änderung zuerst als SELECT schreiben und ansehen.

Fun Facts: SQL

SQL entstand ab 1974 bei IBM und hieß zuerst SEQUEL — der Name war markenrechtlich belegt

Deshalb sprechen viele bis heute „Sequel“ statt „Es-Ku-El“

SQL ist eine deklarative Sprache: man sagt was, nicht wie

Den wie-Teil bestimmt der Abfrageoptimierer des DBMS — oft besser als ein Mensch

Ein vergessenes WHERE bei UPDATE hat schon ganze Kundendatenbanken gleichgemacht
