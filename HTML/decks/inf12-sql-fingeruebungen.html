Vier Fehler und ihre Korrektur

-- falsch: Zeichenketten ohne Hochkommata
SELECT * FROM Schueler WHERE klasse = BGY25;
SELECT * FROM Schueler WHERE klasse = 'BGY25';   -- richtig

-- falsch: NULL mit = vergleichen
SELECT * FROM Belegung WHERE note = NULL;
SELECT * FROM Belegung WHERE note IS NULL;       -- richtig

-- falsch: Spaltenname im falschen Teil
SELECT name WHERE klasse = 'BGY25' FROM Schueler;
SELECT name FROM Schueler WHERE klasse = 'BGY25';  -- richtig

Die Reihenfolge der Klauseln

SELECT — welche Spalten?

FROM — aus welcher Tabelle?

WHERE — welche Zeilen?

ORDER BY — in welcher Reihenfolge?

Diese Reihenfolge ist fest. Gelesen wird die Abfrage aber von FROM her

NULL ist kein Wert, sondern die Abwesenheit eines Werts. Deshalb prüft man mit IS NULL, nie mit = NULL.

Fun Facts: SQL üben

SQL-Island und SQLZoo sind kostenlose Übungsumgebungen im Browser

Der häufigste Anfängerfehler ist das fehlende Hochkomma bei Texten

Der zweithäufigste ist = NULL — es liefert nie ein Ergebnis, aber auch keinen Fehler

Groß- und Kleinschreibung ist bei Schlüsselwörtern egal, bei Daten nicht

Üblich ist trotzdem: Schlüsselwörter groß, Namen klein — der Lesbarkeit wegen
