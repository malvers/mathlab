Kapitel 02

Das Halteproblem

Anschaulich, ohne Beweisformalismus

Nicht verzagen, Doc Alvers fragen!

Die Frage

Gibt es ein Programm H, das für jedes Programm P und jede Eingabe E entscheidet, ob P mit E jemals anhält?

Das wäre nützlich: kein Endlosschleifen-Absturz mehr

Alan Turing bewies 1936: ein solches H kann es nicht geben

Der Beweis führt die Annahme zum Widerspruch — mit einem Selbstbezug

Es ist also keine Frage der Rechenleistung, sondern eine prinzipielle Grenze

Nicht verzagen, Doc Alvers fragen!

Der Widerspruch, in Pseudocode

# Annahme: haelt_an(P, E) existiert und ist immer richtig

def gemein(P):
    if haelt_an(P, P):
        while True:        # dann laufe ewig
            pass
    else:
        return             # sonst halte an

# Und nun: was macht gemein(gemein)?

Nicht verzagen, Doc Alvers fragen!

Der Widerspruch aufgelöst

Hält gemein(gemein) an, dann läuft es laut Definition ewig

Läuft es ewig, dann hält es laut Definition an

Beides ist unmöglich — also war die Annahme falsch

Es kann haelt_an nicht geben. Punkt

Praktische Folge: kein Werkzeug kann alle Endlosschleifen im Voraus finden

Kapitel 03

Numerische Grenzen

Die Grenze, die täglich zuschlägt

Nicht verzagen, Doc Alvers fragen!

Zwei Zeilen, die jeden überraschen

print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False

# Grund: 0.1 ist im Binaersystem eine unendliche Zahl,
# genau wie 1/3 im Dezimalsystem.

# richtig vergleichen:
print(abs((0.1 + 0.2) - 0.3) < 1e-9)   # True
