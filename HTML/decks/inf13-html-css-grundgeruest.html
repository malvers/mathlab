Ein semantisches Grundgerüst

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Vereinsverzeichnis</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header><h1>Vereine in Dresden</h1></header>
  <nav><a href="index.html">Start</a> <a href="liste.html">Liste</a></nav>
  <main><section><h2>Willkommen</h2><p>Kurzer Text.</p></section></main>
  <footer><p>Ein Schulprojekt</p></footer>
</body>
</html>

Semantische Elemente statt div

stattbesserbedeutet
div class="kopf"headerKopfbereich der Seite
div class="menu"navNavigation
div class="inhalt"mainHauptinhalt, einmal je Seite
div class="kasten"section oder articleAbschnitt bzw. eigenständiger Beitrag
div class="fuss"footerFußbereich

Semantische Elemente helfen Screenreadern und Suchmaschinen

Und sie machen den Quelltext für Menschen lesbar

Die Grundformen der Selektoren

/* nach Element */
h1 { color: #1c2b4a; font-size: 2rem; }

/* nach Klasse - beliebig oft verwendbar */
.hinweis { background: #f5f0e0; padding: 1rem; }

/* nach ID - genau einmal je Seite */
#hauptmenu { display: flex; gap: 1rem; }

/* verschachtelt: Links innerhalb der Navigation */
nav a { text-decoration: none; }

Das Box-Modell

TeilistBeispiel
contentder Inhalt selbstder Text
paddingAbstand innen, innerhalb des Rahmenspadding: 1rem
borderder Rahmenborder: 1px solid
marginAbstand außen, zwischen Elementenmargin: 2rem 0

Faustregel: padding innen, margin außen — die Verwechslung ist der Klassiker

box-sizing: border-box lässt Breite inklusive Padding und Rahmen rechnen

Navigation

Was eine brauchbare Navigation ausmacht

Auf jeder Seite dieselbe Navigation, an derselben Stelle

Die aktuelle Seite ist erkennbar markiert

Relative Pfade benutzen, damit es auch beim Umziehen funktioniert

Jeder Link hat einen verständlichen Text — nicht „hier klicken“

Mit der Tastatur erreichbar: Tab-Reihenfolge prüfen

Fun Facts: HTML und CSS

HTML entstand 1991, CSS erst 1996 — dazwischen wurde mit Tabellen layoutet

Das font-Element und blinkender Text gelten heute als abschreckende Beispiele

rem bezieht sich auf die Schriftgröße der Wurzel — deshalb skaliert es mit den Einstellungen des Nutzers

Der Fehler „padding statt margin“ steht in jeder Anfängerliste

Eine Seite ohne CSS bleibt lesbar, wenn das HTML semantisch ist — das ist die Probe
