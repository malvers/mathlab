Flexbox: eine Reihe, die umbricht

.karten {
    display: flex;
    flex-wrap: wrap;        /* umbrechen statt quetschen */
    gap: 1rem;
}
.karte {
    flex: 1 1 260px;        /* wachsen, schrumpfen, Grundbreite */
}

Grid: eine Fläche mit Spalten

.liste {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
    gap: 1rem;
}

/* auto-fit + minmax passt die Spaltenzahl selbst an -
   oft braucht man dafuer gar keine Media Query. */

Media Queries

Wenn es doch eine Grenze braucht

Ab einer Breite anders

/* Grundgestaltung: mobil, eine Spalte */
nav { display: block; }

@media (min-width: 700px) {
    nav { display: flex; gap: 2rem; }
    main { max-width: 70ch; margin: 0 auto; }
}

@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; }
}

Fun Facts: Responsive Design

Den Begriff Responsive Web Design prägte Ethan Marcotte 2010

Flexbox ist für eine Richtung gedacht, Grid für zwei — deshalb ergänzen sie sich

Die Einheit ch entspricht der Breite der Ziffer Null — praktisch für Textbreiten

70 Zeichen je Zeile gelten als gut lesbar, deshalb max-width: 70ch

Die BITV verpflichtet öffentliche Stellen in Deutschland zur Barrierefreiheit
