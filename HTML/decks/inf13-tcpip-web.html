Codeheißttypisch bei
200OKalles in Ordnung

Eine URL zerlegt

TeilBeispielsagt
Schemahttpswelches Protokoll

Pfad/liste.htmlwelche Ressource
Query?ort=Dresdenwelche Parameter

DNS ist ein weltweit verteiltes Verzeichnis — es beantwortet nur die Frage Name zu IP

Antworten werden zwischengespeichert, deshalb wirken Änderungen verzögert

HTTP ist zustandslos: Jede Anfrage steht für sich. 4xx ist euer Fehler, 5xx der des Servers.

Der Statuscode 418 I'm a teapot stammt aus einem Aprilscherz von 1998 und existiert wirklich
