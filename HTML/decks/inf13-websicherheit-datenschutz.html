Passwörter

Niemals im Klartext

Nicht verzagen, Doc Alvers fragen!

Wie ein Passwort gespeichert wird

VerfahrenBewertungwarum
Klartextgrob fahrlässigein Datenleck gibt alles preis
verschlüsseltfalschwer den Schlüssel hat, liest alles
gehasht (MD5, SHA1)veraltetzu schnell, per Wörterbuch knackbar
gehasht mit Salt und langsamem Verfahrenrichtigbcrypt, Argon2

Ein Hash ist eine Einbahnstraße: aus dem Passwort wird ein Wert, zurück geht es nicht

Das Salt ist ein Zufallswert je Nutzer — es verhindert vorberechnete Tabellen

Passwörter richtig behandeln

<?php
// beim Registrieren
$hash = password_hash($passwort, PASSWORD_DEFAULT);
$stmt = $pdo->prepare('INSERT INTO Nutzer (name, pwhash) VALUES (?, ?)');
$stmt->execute([$name, $hash]);

// beim Anmelden
$stmt = $pdo->prepare('SELECT pwhash FROM Nutzer WHERE name = ?');
$stmt->execute([$name]);
$zeile = $stmt->fetch();

if ($zeile && password_verify($passwort, $zeile['pwhash'])) {
    // angemeldet
}

Was geprüft wird

Pflichtfelder: ist überhaupt etwas angekommen?

Länge: eine Ortsangabe mit 5000 Zeichen ist keine

Format: Datum, E-Mail, Postleitzahl — mit passendem Prüfmuster

Wertebereich: eine Jahreszahl 1200 oder 3000 ergibt keinen Sinn

Zugehörigkeit: darf dieser Nutzer diesen Datensatz überhaupt ändern?
