Was beim Sortieren passiert

Die Datenbank ordnet die Zeilen neu — die Daten selbst ändern sich nicht

Aufsteigend: A vor Z, klein vor groß, alt vor neu

Absteigend: genau umgekehrt

Die Sortierung ist nur eine Ansicht; die Tabelle bleibt wie sie ist

Deshalb kann jeder anders sortieren, ohne dem anderen etwas kaputt zu machen

Der häufigste Denkfehler

„Alle Spiele von Kosmos und von Hans im Glück“ — gemeint ist ODER

Denn ein Spiel kann nicht gleichzeitig von zwei Verlagen sein

UND verkleinert die Treffermenge, ODER vergrößert sie

Probe: kommt null Zeilen zurück, war es vermutlich ein UND zu viel

Kommt alles zurück, war es ein ODER zu viel

Fun Facts: Sortieren und Filtern

SQL gibt es seit 1974 und heißt „Structured Query Language“

Eine Datenbank sortiert eine Million Zeilen in Sekundenbruchteilen — mit klugen Verfahren

Damit das so schnell geht, legt sie heimlich einen Index an, wie ein Stichwortverzeichnis

Beim Sortieren von Namen ist Ö je nach Land mal wie O, mal hinter Z einsortiert

Der Filter „enthält“ heißt in SQL LIKE — mit % als Platzhalter
