So baut man eine Tabelle richtig

Eine Sache pro Tabelle: Spiele in die Spieletabelle, Personen in eine eigene

Ein Merkmal pro Spalte: nicht „Kosmos 1995“ in ein Feld, sondern zwei Felder

Jede Zeile einmal: kein Spiel zweimal in der Liste

Ein Feld, das eindeutig ist: die Nummer — daran erkennt man jede Zeile sicher

Dieses eindeutige Feld heißt Schlüssel. Mehr dazu in ein paar Wochen

Fun Facts: Tabellen

Die Keilschrifttafeln aus Mesopotamien vor 5000 Jahren waren schon Tabellen — Listen von Getreide und Vieh

Der Fachbegriff für so eine Tabelle ist Relation — daher „relationale Datenbank“

Eine Tabelle in einer echten Datenbank darf Millionen Zeilen haben, ohne langsam zu werden

Excel ist keine Datenbank: es passt nicht auf, was in eine Spalte kommt

Das Wort Datensatz ist die deutsche Übersetzung von record — „Aufzeichnung“
