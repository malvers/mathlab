Volladdierer — die fünf Gatter

Jede VA-Box hat 3 Eingänge (Bit a, Bit b, Übertrag von rechts) und 2 Ausgänge (Summenbit s, neuer Übertrag c):

  • XOR #1: h = a ⊕ b  (1 genau dann, wenn a ≠ b)
  • XOR #2: s = h ⊕ Übertrag  → das Summenbit
  • AND #1: a ∧ b
  • AND #2: h ∧ Übertrag
  • OR: c = (a∧b) ∨ (h∧Übertrag)  → 1, sobald zwei der drei Eingänge 1 sind

Beispiel 1+1: VA 0 bekommt a=1, b=1 → s = 0, c = 1. VA 1 bekommt 0, 0 und den Übertrag 1 → s = 1. Von rechts gelesen: 10₂ = 2.
