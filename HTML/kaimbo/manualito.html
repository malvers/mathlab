KAIMBOSTUDIO
Manualito — die Kurzanleitung · → zur App

Was ist das hier? Kaimbo Studio ist Dein Autoren-Studio für Sprachlern-Inhalte. Die Grundeinheit ist der Task: ein Satz oder Wort in fünf Sprachen (Deutsch, Italienisch, Spanisch, Englisch + eine „Flexi“-Sprache, historisch Französisch) mit Bild, Ton und eigenem Lernstand pro Sprache. Du blätterst, hörst, tippst im Quiz — und das Studio merkt sich per Spaced Repetition, wann welcher Task wieder dran ist.

1SCHNELLSTART

  1. App öffnen — kaimbo/kaimbo.html im Chrome.
  2. Ordner verbinden — oben rechts auf den roten Chip „no folder“ klicken und KaimboStudio/DataLearnLanguages auswählen. Ab jetzt liest und schreibt die App direkt Deine echten Dateien (Vocabulary.txt, mytopics.pnk, Bilder, Sounds) — mit automatischen Backups. Der Chip wird grün.
  3. Blättern — ↓ / ↑ zeigen den nächsten/vorigen Task. Das war’s, Du bist drin.
Ohne verbundenen Ordner läuft alles genauso — nur eben im Browser-Speicher (localStorage). Der grüne Weg ist der richtige: Java-App und Web-App können sich denselben Datenordner teilen.

2DIE OBERFLÄCHE

BereichWas er tut
TopbarMenüs (File/Edit/View/Select/Modi/Help), das Suchfeld und der Ordner-Chip.
LinksZwei Tabs: Language filters (Filterliste + Dein Themenbaum) und Special filters (Qualitäts-Checks). Breite per Ziehen am Rand, Ctrl O blendet alles aus.
MitteDrei Tabs: Learning (die Hauptansicht: Bild + Sprachzeilen), Task List (Tabelle aller gefilterten Tasks, Klick springt hin), Help (Shortcuts).
StatusleisteUnten: welcher Task, wie viele sichtbar/insgesamt, und rechts der Wiederholungs-Zähler („n to repeat“).

In der Learning-Ansicht liegen drei Ecken-Buttons auf dem Bild: oben rechts 🗑 Task löschen, unten rechts ＋ neuer Task, unten links ⓘ Notiz zum Task (der Punkt wird grün, wenn eine Notiz existiert). Ein roter Punkt oben links heißt: „Task braucht noch ein richtiges Bild“. Klick auf freie Bildfläche versteckt die Textzeilen (und holt sie zurück).

4NEUE TASKS & BILDER

  1. Ctrl N (oder ＋) öffnet den Dialog. Tippe Deinen Satz in genau ein Sprachfeld — das hellgrüne Feld ist die Quelle.
  2. Enter → die anderen vier Sprachen werden automatisch übersetzt. Einzelne Übersetzungen kannst Du danach direkt korrigieren.
  3. Noch mal Enter → Task wird gespeichert (ganz vorn einsortiert), die Felder leeren sich für den nächsten. Esc verwirft/schließt.

Bild dazu: Bild kopieren und mit Cmd V einfügen — oder eine Bilddatei einfach auf die Learning-Fläche ziehen. Es landet als Datei in images/, benannt nach dem englischen Text. Zurechtrücken: Alt ←→↑↓ verschiebt, Alt +/Alt --Tasten (Alt ]/Alt / auf US-Layout) zoomen, Alt R setzt zurück — alles pro Task gespeichert. Bildersuche: Rechtsklick auf eine Sprachzeile → Pixabay / Unsplash / Google Images.

Ctrl E editiert den aktuellen Task (Änderungen greifen sofort), Backspace löscht ihn (mit Rückfrage), Ctrl I markiert „braucht neues Bild“.

5LERNEN: QUIZ & WIEDERHOLUNG

Ctrl C deckt die Master-Sprache zu — jetzt bist Du dran: tippe den Satz. Die Farbe sagt Dir live, wo Du stehst:

FarbeBedeutung
grünExakt richtig! Ton spielt, kurz danach kommt automatisch der nächste Task.
hellgrünStimmt bis hierhin — weiter so.
cyanKommt im Satz vor, aber nicht am Anfang.
rot + „Dong“Falsch abgebogen. Ab dem dritten Fehler steigt der Task eine Lernstufe ab.

Dahinter steckt: Jeder Task hat pro Sprache einen Repeats-Zähler und eine Lernstufe in Tagen:

0→1→ 2→4→ 7→14→ 60→180 Tage

Richtig getippt halbiert die Repeats; bei 0 klettert der Task eine Stufe hoch und ist erst nach der Wartezeit wieder fällig. Fehler (auch manuelles Aufdecken mit Ctrl C!) zählen als Fehlversuch. Die Badges auf der Master-Zeile zeigen den Stand: orange = heute fällige Tasks (grüner Smiley = nichts fällig), blau = Lernstufe in Tagen, grau = Datum der nächsten Wiederholung, rechts der Repeats-Zähler (grün = gelernt). Sind beim Start Wiederholungen fällig, springt die App automatisch in „Show not learned“. Ctrl P zeigt die Statistik: wie viele Tasks an welchem Tag fällig werden.

6DIE MASTER-SPRACHE

Genau eine Sprachzeile ist die Master-Sprache (weiß hinterlegt) — Du wechselst sie mit einem Klick auf den linken Rand einer Zeile (Kästchen + Sprachkürzel). Sie bestimmt: wo die Suche sucht, was im Quiz abgefragt wird, welche Sprache Statistik/Filter/„learned“ meinen und was der Recorder aufnimmt. Kurz: Master = die Sprache, die Du gerade lernst. Die fünfte Zeile („Flexi“) stellst Du unter Modi → Choose flexible language um.

7DER THEMENBAUM

Themen sortieren Deine Tasks — die Zuordnung passiert automatisch: ein Thema „fängt“ alle Tasks, deren englischer Text das Themenwort enthält (als ganzes Wort) oder gleich ist. Die Zahl rechts ist der Treffer-Count (inklusive Unterthemen).

AktionSo geht’s
Checkbox klickengrün = Filter an: nur noch Tasks der angehakten Themen (inkl. Unterbaum) sind sichtbar. Rechtsklick auf die Box = blau (additiv dazu). Nochmal klicken = aus.
Label klickenWählt das Thema aus und schiebt seinen Namen in die Suche.
DoppelklickThema umbenennen. ▸/▾ klappt auf und zu.
Shift+KlickNeues Unterthema, benannt nach dem aktuellen Task.
RechtsklickAlles Weitere: neues Thema, löschen, gruppieren, Cut/Copy/Paste, hoch/runter, sperren, Struktur-Knoten, Export/Import, Undo/Redo (Ctrl Z).
EscAlle Häkchen weg, alle Tasks wieder sichtbar.

8FILTER

Über dem Baum sitzt die Select-Liste: Show all / not learned / learned, „no image“, „need new image“, „no sound“, „unclassified“ sowie die Lernstufen (New today, Level 1–6, Learned). Ein Klick = Filter aktiv, die Learning-Ansicht springt zum ersten Treffer. Im Tab Special filters findest Du dieselben Qualitäts-Checks als Checkboxen mit Treffer-Zähler — perfekt zum Aufräumen („welche Tasks haben noch kein eigenes Bild?“). Esc oder Klick ins Leere stellt alles zurück.

9TON & RECORDER

Der ▶-Knopf rechts in jeder Zeile spielt den Ton: zuerst eine echte WAV-Datei aus sounds/<sprache>/ (Person-Icon = Deine eigene Aufnahme), sonst die Browser-Sprachausgabe. Eigene Stimme aufnehmen: Ctrl R öffnet den Recorder — roter Knopf startet/stoppt (blinkt beim Aufnehmen), danach spielt die Aufnahme automatisch ab und wird unter Sprecher_Text_Stimme.wav im Ordner gespeichert. Space = nochmal anhören, ↑/↓ = Task wechseln, Klick auf den Namen unten = Sprecher umbenennen, Esc = schließen.

10DER SIMULATOR

Alt S zeigt das Handy-Preview: Deine Themen als sieben bunte Knöpfe. Klick bohrt in die Unterthemen, Rechtsklick geht hoch. Ein Klick auf ein Blatt-Thema (oder Alt-Klick → einen Modus wählen) startet den Play-Modus: Bild + italienischer und deutscher Balken, beide werden vorgelesen, dann kommt automatisch die nächste Karte. Balken antippen (de)aktiviert die Sprache, Maus drüber zeigt die Steuerung (Play/Pause, vor/zurück), Esc beendet.

11DEINE DATEN

Datei/OrdnerInhalt
Vocabulary.txtAlle Tasks — das Original-Format, 1:1 kompatibel zur Java-App.
mytopics.pnkDer Themenbaum (inkl. Aufgeklappt-Zustand).
images/ · sounds/Task-Bilder und Ton-Dateien.
Infos_*/Deine Notizen aus dem ⓘ-Fenster.
backup/Zeitgestempelte Sicherungen — bei jedem Laden automatisch (Tasks und Baum).

Gespeichert wird bei jeder Änderung automatisch, Ctrl S erzwingt es. File → Import/Export tauscht einzelne .txt-Pakete und .pnk-Teilbäume aus (z. B. „Italy.pnk“). Übersetzt wird standardmäßig über den freien MyMemory-Dienst; unter File → Translate settings kannst Du einen eigenen Google-Key hinterlegen — der bleibt ausschließlich in Deinem Browser.

Falls mal etwas klemmt: Ctrl L öffnet das Debug-Fenster mit dem Log. Und wenn eine Datei beschädigt aussieht, lädt die App sie gar nicht erst und speichert auch nichts — Original und backup/ bleiben unangetastet.
