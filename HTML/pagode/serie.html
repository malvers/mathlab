230 SL Pagode — Serien-Schaltung (ohne unser BLE-Zeug)

Original W113 · Start & Zündung · → zur BLE-Fernsteuerung

So funktioniert die Serie (ohne unser Zeug)

Start: Schlüssel auf Start → Zündschloss verbindet Kl.30 → Kl.50 → Anlasser-Magnetschalter zieht an, sein interner Hauptkontakt legt den 200–500 A-Strom von Kl.30 auf den Anlassermotor. Lässt man los, federt der Schlüssel auf Fahrt zurück, Kl.50 fällt ab.
Zündung: In Fahrt verbindet das Zündschloss Kl.30 → Kl.15 → Vorwiderstand (0,9 Ω) → Zündspule Kl.15. Die Spule lädt sich, der Unterbrecher im Verteiler taktet Kl.1 gegen Masse; bei jedem Öffnen bricht das Feld zusammen → Hochspannung an Kl.4 → Verteiler → Kerze. Beim Anlassen wird der Vorwiderstand überbrückt (volle Spannung trotz Spannungseinbruch).
Stop: Schlüssel auf 0 → Kl.15 stromlos → kein Funke. Genau hier setzt unser BLE-Umbau an: Kanal-2-Öffner in die Kl.15-Leitung, Kanal-1 + Bosch-Relais auf Kl.50. Kl.1 und Kl.4 bleiben unangetastet.
