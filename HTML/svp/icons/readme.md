# Zeichen im Neuigkeiten-Band und in der Materialliste

Fremde Marken und Grafiken liegen hier als Datei, statt sie von der Quelle zu laden:
sonst meldet jeder Aufruf einer Planseite die IP der Schuelerin oder des Schuelers an
einen fremden Server. Verwendet werden sie als Quellenangabe, mit Link auf die Meldung.
