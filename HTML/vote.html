So geht's

  1. Fach / Klasse wählen (Feld neben dem Code) und Frage tippen — direkt in die orange Zeile.
  2. Publish — die Frage geht live, die Bühne zeigt 0.
  3. QR zeigen (Button oben rechts) — alle scannen oder tippen docalvers.de/vote.html und den 4-stelligen Code.
  4. Jede:r tippt einmal 1 … 10. Der Zähler läuft live hoch.
  5. Show — die Auswertung: Verteilung 1 … 10 als Balken, der Mittelwert groß im Bild, darunter die Klasse aus dem Stundenplan. Count, Klick aufs Bild oder Esc = zurück zum Zähler.
  6. Neue Frage — Text ändern, drücken: gleicher Code, alle springen automatisch mit und dürfen wieder einmal voten.
  7. ◀ ▶ — durch alle bisherigen Fragen blättern, quer über alle Codes (mit Datum · Zeit, n und Mittelwert). Der Code im Feld springt mit.
  8. Neuer Survey — neuer Code für eine neue Klasse; die alte Frage wird geleert.
  9. C (oben rechts) — löscht die Frage, die gerade auf der Bühne steht, samt ihrer Stimmen. Nach Rückfrage, und nur am Rechner, an dem sie angelegt wurde. ⌫ tut dasselbe.
  10. Session aufgreifen — Code eintippen, dann kommt die letzte Runde dazu zurück: an jedem Rechner, auch lokal. Als Link geht auch vote.html?host&code=5577.
